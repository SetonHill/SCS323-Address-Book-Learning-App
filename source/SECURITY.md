# Security

Use synthetic records only. Never commit `.env`, credentials, tokens, keys, private addresses, backups, database dumps, or real contact information.

If a secret is suspected, stop the workflow and notify the instructor privately. Revoke or rotate it, remove it from the current tree, determine whether history remediation is required, and verify scans. Never paste it into an issue, pull request, screenshot, chat, or evidence. Secret findings are not student-overridable.

This v1 teaching app has no authentication and must not be exposed as a real public address book. Report dependency or implementation concerns privately without including exploit payloads containing sensitive values.
