# Project Definition

Version: 1.0.0

The Address Book demonstrates a bounded browser → FastAPI route → validation → SQLAlchemy → PostgreSQL → Jinja response path. Contacts are the root entity; addresses and phone numbers are dependent one-to-many entities. It deliberately excludes authentication, real personal data, external APIs, file uploads, and JavaScript framework complexity.

Acceptance means the documented Compose build, migration, seed, health, readiness, tests, responsive UI, and safe reset all work from a clean extraction.
