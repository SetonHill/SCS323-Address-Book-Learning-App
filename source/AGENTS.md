# Repository Agent Rules

Agents are advisory and read-only unless a student explicitly asks for a bounded draft and then reviews every change.

- Issue Planner is required before each substantial change.
- Pull Request Reviewer is required before each substantial merge.
- Repository Steward is required at milestone close and release candidate.
- Record the invocation, output, and disposition of every finding.
- Agents cannot approve, merge, deploy, grade, invent evidence, or replace student understanding.
- On outage, record the time/error, complete the equivalent manual checklist, obtain peer review when available, and disclose the outage.
- On a likely secret, stop immediately, do not quote it, and follow `SECURITY.md`. Secret findings cannot be overridden.
